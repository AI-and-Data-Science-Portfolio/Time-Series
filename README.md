# Time-Series

Project Goal:

The aim of this report was to practice ETS and ARIMA forecasting methods. The report sought to predict unemployment in Ireland in 2025 based on historical employment figures.

Key Findings:

ARIMA was found to be the more suitable of the two prediction methods for the data.

Outputs:

All charts, summaries, tables, etc. can be viewed in [Time Series Project](docs/Time%20Series%20Project.pdf) 

How to Run:
1. Download or clone this repository to your computer.
2. Open RStudio and install the required packages:
   
   ```r
   install.packages(c("forecast", "fpp2", "fpp3", "ggpubr", "ICSS", "readxl", "tseries", "zoo"))
   ```
4. Open [`src/Time Series Project.R`](src/Time%20Series%20Project.R) and run the script from top to bottom.
